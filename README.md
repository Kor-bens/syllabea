# Syllabéa

Application pour apprendre à lire (syllabes, mots, voix) — 4 ans et plus.

Site statique : ouvrir `index.html` ou déployer sur Netlify.

## En ligne (Netlify)

1. Aller sur [app.netlify.com](https://app.netlify.com)
2. **Add new site → Import an existing project**
3. Choisir GitHub et le dépôt `syllabea`
4. Publish directory : `.` (la racine)
5. Deploy

Ensuite l’adresse ressemble à `https://syllabea-xxxxx.netlify.app`.
On peut la mettre sur l’écran d’accueil du téléphone.

## Local

Ouvrir `index.html` dans Chrome ou Safari. Garder le dossier `audio/` à côté.
